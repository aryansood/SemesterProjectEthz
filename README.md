# e2e_driving
### Python Environment
Install python 3.10.13.

Install the Cuda toolkit if not already present

```bash
python -m venv env-name
source env-name/bin/activate
pip install waymo-open-dataset-tf-2-12-0==1.6.7
pip install -r requirements.txt
```
